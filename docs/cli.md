# CLI Reference

```bash
tokenledger summary          # Show aggregated usage
tokenledger summary --detail # With per-provider breakdown
tokenledger export --format csv -o out.csv
tokenledger export --format json -o out.json
tokenledger verify           # Check checksum integrity
tokenledger compact          # Force retention pruning
tokenledger health           # Store health and stats
tokenledger update-pricing   # Reload pricing from JSON file
```
